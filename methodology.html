Methodology

How Source Finder works.

What the AI does. A live request first uses Anthropic's Claude Sonnet 5. If it cannot complete a usable grounded run, the server makes one backup attempt with OpenAI's GPT-5.6 Terra. The active model reads your text, searches the web and proposes sources across four blindspot categories. Server-side code then drops every suggestion that is not backed by an actual search result URL — if the model cannot ground a suggestion in a search it ran, you never see it. The page tells you how many were dropped. An example only loads text into the box; the green button runs it live. If a live example fails, the page can show a labeled saved result that is re-checked through the same gate in your browser.

What gets sent. Live text is sent to Anthropic first. If that attempt cannot finish with usable grounded results, the same text is also sent to OpenAI for the backup attempt. Search queries go out to the web. Nothing is stored by this site; there is no database, and page-view analytics never receive the text anyone types. Because the text leaves your machine, never paste confidential material: unpublished source identities, off-the-record information, sealed records, or anything a source shared in confidence.

What it never does. It does not judge whether your story is good. It does not contact anyone. It does not replace your editor: every suggestion is a lead to verify with your own reporting before you rely on it. The model is instructed to suggest organizations, officials, public records and expert roles — not private individuals.

How this fits newsroom AI standards. Hearst's published AI-use principles permit generative AI to support reporting and research by organizing and surfacing material "which is then evaluated by reporters and editors," under editorial oversight and with clear disclosure. This tool is built to live inside that box: AI is not a journalist here — it surfaces leads, the page labels everything the model touched, and a journalist evaluates every item before it goes anywhere near a story.

Who this is for. This is an internal newsroom tool for reporters and editors — not a public product, and nothing it produces is for publication. Every result is unverified information until a journalist confirms it through their own reporting.

Where the examples come from. Each sample draft was written for this demo by Claude, the same AI that powers the tool, working from a real, linked Houston Chronicle article: the article was read, its facts were kept, and new prose was written from scratch. No Chronicle sentences are reproduced, and every sample credits and links the original story it draws on. The story-idea examples are assignments written for this demo about real, publicly reported Houston matters.
